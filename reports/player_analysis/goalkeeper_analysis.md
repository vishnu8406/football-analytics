# Goalkeeper Analysis

## Overview

This analysis evaluates goalkeeper performance during the season using shot-stopping, distribution, and defensive contribution metrics. The objective is to identify the league's most effective goalkeepers based on saves, goals conceded, save percentage, penalty-saving ability, and involvement outside the penalty area.

---

## Metrics Used

| Metric | Description |
|----------|----------|
| Matches Played | Number of matches played by the goalkeeper |
| Shots Faced | Total shots faced |
| Saves | Total saves made |
| Goals Conceded | Goals allowed |
| Save Percentage | Saves ÷ Shots Faced × 100 |
| Penalties Saved | Penalty kicks successfully saved |
| Punches | Punch clearances made |
| Sweeper Actions | Defensive actions outside the penalty area |
| Saves per Match | Average saves per match |
| Goals Conceded per Match | Average goals conceded per match |

---

## Key Findings

### Elite Shot-Stoppers

**Xabier Iruretagoiena Aranzamendi** recorded the highest save percentage in the dataset at **72.22%**, conceding only **7 goals** from **18 shots faced**. Although the sample size is relatively small, the efficiency is exceptional.

**Raúl Lizoáin Cruz** finished with a **50.70% save percentage**, making **36 saves** while conceding only **11 goals**, demonstrating consistent shot-stopping ability across a full season.

**Francisco Casilla Cortés** also performed strongly with a **44.83% save percentage** and only **6 goals conceded** in **38 appearances**.

## Conclusion

The goalkeeper analysis reveals distinct goalkeeper profiles across the league:

- **Xabier Iruretagoiena Aranzamendi** achieved the highest save efficiency.
- **Antonio Adán Garrido** handled the greatest shot volume.
- **Jan Oblak** produced the strongest combination of defensive stability and consistency.
- **Keylor Navas** stood out as the league's top penalty-saving goalkeeper.
- **Vicente Guaita Panadero** demonstrated the most complete all-around involvement through saves, punches, and sweeper actions.

Overall, goalkeepers who combined strong save percentages with low goals-conceded rates provided the greatest defensive value to their teams throughout the season.
